How the THEMIS marker regions were produced
===========================================

To re-generate the marker regions from THEMIS, first download the `CIN_matrix.txt`, `MFR_matrix.txt`
and `FSI_regions.txt` files available at
[https://github.com/yulongbio/themis/tree/main/Data](https://github.com/yulongbio/themis/tree/main/Data),
and place them in the current directory.

Next, run the `make-marker-lists.py` script to get the 3 list of marker regions.
